# Hatırlatıcı (Android)

Sesli not söyle → uygulama zamanı ve ne hatırlatacağını anlasın → zamanı gelince alarm gibi çalsın.

## APK nasıl alınır (ücretsiz, bilgisayara bir şey kurmadan)
1. GitHub'da yeni bir repo aç (ör. `hatirlatici`).
2. Bu klasörün İÇİNDEKİ her şeyi (`.github`, `app`, `build.gradle.kts`, ...) repoya yükle (Add file → Upload files).
3. Repo'da **Actions** sekmesine git. "APK derle" çalışır (3-5 dk).
4. Bitince repo ana sayfasında sağdaki **Releases** bölümünden `app-debug.apk` dosyasını telefona indir ve kur
   (Android "bilinmeyen kaynaklardan yükleme" izni isteyecek).
